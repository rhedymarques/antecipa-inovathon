# Orientação para assistentes de IA

Antes de alterar este projeto, leia `HANDOFF.md`, `README.md`, `GUIA_DO_GRUPO.md` e `dist/alinhamento-proposta.md`.

- Continue a implementação existente; `dist/` contém código-fonte servido, não apenas artefatos descartáveis.
- O backlog do handoff é uma proposta. Execute a tarefa solicitada pelo colega, não todos os itens automaticamente.
- Preserve a identificação de dados sintéticos e os limites das previsões e integrações.
- Ao modificar contas de caixa, execute `node work/test_engine.js` e verificações pertinentes de interface.
- O repositório é privado. GitHub e Sites têm históricos, acesso e publicação separados; não force sincronização nem altere a visibilidade sem instrução.
- Ao concluir, atualize `HANDOFF.md` com o que realmente mudou, o que foi verificado e o que continua pendente.
